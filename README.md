# FlameCheck

FlameCheck — Gaming deals, game price comparison, free games, price tracking, CS2 skin prices and interactive maps. Available in Uzbek, Russian and English.

Live: https://flamecheck.bid. Static files only (Cloudflare Workers Static Assets): no server code, no database.
Rules for AI assistants: [AGENTS.md](AGENTS.md). Sister site: [ruzmatvv/FrameCheck](https://github.com/ruzmatvv/FrameCheck).

| Command | What it does |
| --- | --- |
| `npm test` | Runs the tests. |
| `npm start` | Local copy of the site (wrangler dev). |
| `npm run sync` | Copies the shared CS2 files from the FrameCheck folder next to this one. |
| `npm run deploy` | Manual deploy (needs a signed-in Cloudflare account). |
